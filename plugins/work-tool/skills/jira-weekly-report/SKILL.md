# Jira 工时表周报生成

## 核心能力
- 读取 Jira TimeWise 工时表数据
- 按标准模板生成周报邮件文案
- 自动识别本周（周一至当前工作日）工时条目

## 触发条件
用户说"发周报"、"生成周报"、"本周工作周报"、"周报"，或发送 Jira 工时表链接。

## 数据获取流程

### 步骤1：打开工时表
1. 直接使用 Playwright 打开固定链接：`https://jira.jctrans.com/secure/shdsd-TimeWise-TimeSheet.jspa`
2. 提示用户："请登录后告诉我"
3. 等待用户确认登录完成

### 步骤2：打开并登录
1. 使用 Playwright 打开固定链接：`https://jira.jctrans.com/secure/shdsd-TimeWise-TimeSheet.jspa`
2. 获取页面快照，检查是否显示登录界面（如用户名输入框、登录按钮等）
3. 如判断为需登录，提示用户："请登录后告诉我"
4. 如判断为已登录（页面显示用户信息或工时表内容），继续下一步
5. 等待用户确认登录完成后，获取完整页面数据

### 步骤3：读取工时数据
1. 获取页面快照（browser_snapshot）
2. 解析以下信息：
   - 用户姓名（页面头部显示）
   - 时间区间（页面显示的周期，如 "2026-06-08 ~ 2026-06-28"）
   - 所有工时条目（项目名、任务描述、任务编号、状态、计划工时、日志工时）
3. 筛选本周数据（本周日期范围：周一 00:00 ~ 周日 23:59，取当前已过工作日）

### 步骤4：读取记忆信息
读取项目记忆文件（如存在），获取：
- 用户姓名
- 汇报周期规则
- 如记忆缺失，在生成周报前询问用户

## 周报模板

按以下固定模板生成：

```
[姓名] · [年份]第[周数]周工作汇报（[开始日期] - [结束日期]）

一、待决策事项
[填写内容，无则写"无"]

二、工作重点事项汇报

主要完成以下项目功能开发：

[按模块分组，每模块格式如下：]
[模块名]（[模块英文缩写]）
- [(1) 完成[任务描述]，相关子任务已关闭，投入[X]h。]
- [(2) 完成[任务描述]，投入[X]h。]
- [(3) [任务描述]（[任务编号]）进入[状态]，推进中。]

三、下周重点工作

[按优先级列出3-5条下周计划，格式如下：]
[数字序号]. [任务描述]，目标[完成目标/里程碑]。

---

📊 本周工时：[总工时]h（[模块A] [工时]h / [模块B] [工时]h / ...）
📅 周期：[开始日期] ~ [结束日期]
```

## 工时数据解析规则

### 项目模块识别
根据 Jira 项目名识别模块：
- "JCtrans国内小程序"、"JCMI" → JCtrans国内小程序（JCMI）
- "帮货代" → 帮货代日常迭代（BHD）
- "国际站"、"XZZ" → 国际站（XZZ）
- "会议产品"、"会议" → 会议产品
- 其他项目名 → 按实际名称，不可省略或合并

### 任务状态解读
| Jira 状态 | 周报描述 |
|-----------|---------|
| 已关闭、已完成 | ✅ 已关闭 |
| 已上线 | ✅ 已上线 |
| SIT测试中、待测试 | 🔄 SIT测试中/待测试 |
| 开发中 | 🔄 开发中 |
| 待处理 | ⏳ 待处理 |

### 工时分配规则
- 日志工时（区间日志列）为本月实际投入
- 计划工时（区间计划列）为预估工时
- 报告时使用"投入[X]h"描述
- 0h 工时但有相关子任务的，说明状态推进情况

### 同一任务的 MP 版本的处理
如果同一任务有"MP"前缀的对应任务（如 JCMI-891 和 JCMI-931），周报中可合并描述：
- "MP [任务名]（[MP版本编号]）已完成，原始版本（[原版本编号]）进入测试"

## 交互流程

### 完整流程
1. 用户触发（说"发周报"或发链接）
2. 获取/确认 Jira 链接
3. 打开页面，等待用户登录
4. 读取页面数据
5. 读取记忆信息
6. 如缺少关键信息（姓名等），询问用户
7. 生成周报文案
8. 展示给用户

### 询问话术标准
- 缺链接："请提供 Jira 工时表链接"
- 缺姓名："请告诉我你的姓名"
- 缺其他信息时，按需询问

## 记忆读取
读取以下记忆键（如存在）：
- `jira_weekly_report_name`: 用户姓名
- `jira_weekly_report_cycle`: 汇报周期说明
- `jira_weekly_report_recipients`: 汇报对象

## 输出
生成 `.doc` 格式文件，使用 `document-skills:docx` skill 生成。

### 输出流程
1. 使用 `document-skills:docx` skill 生成周报文档
2. 按模板生成周报内容
3. 保存为 `周报_[姓名]_[日期].doc`
4. 告知用户文件路径
